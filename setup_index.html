📋 Paso 1: Instalar Base de Datos

El asistente auto_setup.php solicitará host, usuario, contraseña y nombre de la base de datos. Solo si la conexión es válida actualizará la configuración del sistema y ejecutará la instalación.

  • ✓ Validación previa de credenciales MySQL
  • ✓ Actualización automática de config/config.php
  • ✓ Creación o uso de la base de datos indicada
  • ✓ 10 tablas necesarias
  • ✓ 5 roles predeterminados
  • ✓ 32 permisos por módulo
  • ✓ Usuario administrador
